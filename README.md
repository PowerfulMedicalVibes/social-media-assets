# social-media-assets

Public, permanent links for **approved** Powerful Medical social posts (images, PDF carousels),
served by GitHub Pages at `https://powerfulmedicalvibes.github.io/social-media-assets/`.
Buffer downloads media from these links when a post goes out.

- Files are added only after a person approved that exact version in Slack (pm-social workflow).
- Path: `posts/<YYYY-MM>/<post-id>/v<n>/<file>` (e.g. `posts/2026-10/2026-10-25-acep-quiz-winners/v3/carousel.pdf`).
- Never edit or delete a file after its post is scheduled or published; a new version gets a new folder.
- Nothing confidential here: everything in this repo is public.

Maintained by Claude in Slack and Robert Herman.
